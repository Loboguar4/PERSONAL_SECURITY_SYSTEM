# Contribuindo com o _DAEMON

Obrigado por considerar contribuir com o projeto!

O _DAEMON é um jogo open source em Python, focado em simulação sistêmica, narrativa e mecânicas de risco e reputação.

## Tipos de contribuição bem-vindos

- Correção de bugs
- Balanceamento de sistemas
- Expansão de conteúdo narrativo
- Novas IAs, eventos e facções
- Otimizações e refatorações
- Documentação

## Como começar

1. Faça um fork do repositório
2. Crie uma branch para sua modificação:
  "git checkout -b minha-feature"
3. Faça commits claros e pequenos
4. Envie um Pull Request explicando o que foi feito

## Boas práticas

- Use nomes de funções e variáveis claros
- Preserve o estilo procedural/modular do projeto
- Evite dependências externas (o projeto usa apenas stdlib)
- Comente trechos complexos
- Teste o jogo antes de submeter PR

## Onde contribuir mais facilmente

- Arquivos de missões e eventos (`sg_*`)
- Balanceamento de itens, skills e risco
- Sistemas de IA e spawn
- Diálogos e narrativa ramificada

## O que evitar

- Inserir bibliotecas externas sem discussão prévia
- Mudar drasticamente a arquitetura sem issue associada
- Remover mecânicas sem justificativa
